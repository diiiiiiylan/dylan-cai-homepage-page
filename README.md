# dylan-cai-homepage-page

Public static build output for the Dylan Cai homepage.

This repository is intended to host the generated static page assets. The source
project is kept separately in `diiiiiiylan/dylan-cai-homepage`.

## Contents

- `index.html`: generated homepage entry.
- `assets/`: static assets referenced by the generated page.
- `.nojekyll`: keeps GitHub Pages from applying Jekyll processing.

## Maintenance

Update this repository from the source project build output. Avoid hand-editing
generated assets unless the source repository is unavailable.
